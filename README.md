# KIPLang — платформа изучения языков
WPF-приложение для записи на языковые курсы, прохождения уроков и управления контентом.
## Стек

- **C# / .NET Framework** (WPF)
- **XAML** — интерфейс
- **Entity Framework 6** — работа с БД
- **SQL Server** — хранение данных
- **MVVM-подобная структура** — Pages + UserControls

## Роли
| **Студент** | Каталог курсов, оплата и запись, уроки, тесты, прогресс, отзывы, достижения |
| **Преподаватель** | Создание/редактирование курсов, уроки, заморозка курса, список студентов, статистика |
| **Администратор** | Пользователи (смена ролей), все курсы, модерация отзывов, общая статистика |

## Основные функции

- Регистрация / вход (капча, валидация email и пароля)
- Светлая и тёмная тема (тумблер)
- Каталог и страница курса
- Оплата (имитация) и запись на курс
- Прохождение уроков: материал, упражнения, тесты
- Отзывы и рейтинг
- Профиль с вкладками по ролям

## Структура

Pages/           — экраны приложения
Pages/UserElements/  — вкладки профиля (UserControls)
Pages/LoginElements/ — вход и регистрация
res/             — темы (Light / Dark)
Images/          — логотип
